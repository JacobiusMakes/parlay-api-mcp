# Support

Questions and bug reports are welcome. Email to support@parlay-api.com is recorded in the support ticket system and may receive an automated acknowledgment before a substantive reply. Response and fix times vary; no same-day commitment is implied.

## Where to go

- **Bug reports:** [open an issue](https://github.com/JacobiusMakes/parlay-api-mcp/issues).
- **Questions and ideas:** [GitHub Discussions](https://github.com/JacobiusMakes/parlay-api-mcp/discussions)
- **Email:** support@parlay-api.com
- **Docs:** https://parlay-api.com/docs

## What helps

For bugs, the fastest turnaround comes from: your `parlayapi-mcp` version, which MCP client you are using (Claude Desktop, Claude Code, Cursor, other), a redacted client config snippet, and what the tool call returned versus what you expected. Remove API keys, credentials and private account data before sharing.
